🏗️ estruturas do HTML5

O que é HTML

HTML (HyperText Markup Language) é a linguagem que dá estrutura para páginas da web. Pensa nele como o “esqueleto” do site — define o que aparece na tela: textos, imagens, links, listas, formulários, etc.

Ele usa tags (etiquetas) para marcar cada parte do conteúdo.

Exemplo básico de tag:

estrutura básica de um HTML

Todo arquivo HTML segue uma base Parecida:

•<!DOCTYPE html> → Diz ao navegador que é um documento HTML5

•<html> → Raiz do documento

•<head> → Configurações, título, links de CSS, fontes, metadados

•<body> → O que realmente aparece na página

🏷️ Tags Iniciais Importantes

•<h1> até <h6> → Títulos (h1 = maior, h6 = menor)

•<p> → Parágrafos

•<a>→ Links

•<img> → Imagens

•<div> e <span> → Agrupar ou organizar conteúdo

🔗 Tags de links

Para criar um link:

•href → Para onde o link aponta

•target="_blank" → Abre em nova aba
