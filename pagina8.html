estruturas do CSS3

🎯 O básico do CSS

CSS serve pra dizer como os elementos HTML vão parecer: cor, tamanho, posição, espaçamento, etc.

A regra geral é:

🏷️ Seletores

📏 Espaçamentos: margin e padding

• margin: espaço fora do elemento (afasta dos outros).

• padding: espaço dentro do elemento (afasta o conteúdo das bordas).

Dica: você pode usar valores diferentes pra cada lado:

📦 Dimensões: width e height

• width: largura.

• height: altura.

Pode usar % (percentual da tela ou do elemento pai) ou auto.

🖼️ Fundo (background e background-color)

• background-color: só a cor de fundo.

• background: pode ser cor, imagem, repetição, posição, tudo num só.

🖋️ Texto (text-align e companhia)

• text-align: alinha horizontalmente o texto (left, right, center, justify).

• color: cor da fonte.

• font-size: tamanho da fonte.

• font-weight: negrito (bold).

📐 Displays

Define como o elemento se comporta no fluxo da página:

• block → ocupa a linha toda (ex: <div>, <p>).

• inline → ocupa só o espaço do conteúdo (ex: <span>, <a>).

• inline-block → mistura: respeita altura/largura, mas fica na linha.

• flex → ativa layout flexível (muito usado pra centralizar, alinhar e distribuir).

• rid → layout em grade.

🔧 Outras propriedades muito usadas

• border → bordas.

• border-radius → arredonda cantos.

• overflow → controla conteúdo que vaza.

• position → posicionamento.
